# Shipping company website plan

## Goal
Create a polished shipping-company website that closely follows the uploaded reference once it is available, while using original placeholder branding and copy. No charts will be included.

## Pages and content
- Build the main page at `/` with the reference’s overall hierarchy, spacing, and visual rhythm.
- Recreate the visible navigation, main banner, service highlights, company introduction, calls to action, and footer shown in the reference.
- Use realistic placeholder company details, service names, contact information, and shipping-focused imagery where the reference does not supply usable content.
- Add separate pages only for major destinations visibly linked in the reference, so navigation never leads to unfinished pages.

## Visual treatment
- Match the reference’s colors, typography, image treatment, proportions, and desktop/mobile behavior as closely as practical without copying protected brand marks or proprietary assets.
- Add restrained shipping-themed creative details where the screenshots leave gaps.
- Keep every section clear and readable across desktop and mobile screens.

## Motion and interaction
- Add subtle entrance reveals, navigation and button feedback, and gentle image movement.
- Respect reduced-motion preferences and avoid distracting continuous animation.
- Implement expected menu and call-to-action interactions; omit all chart-related UI.

## Quality checks
- Verify navigation and interactive elements in the running preview.
- Inspect desktop and mobile layouts for clipping, overlap, and readable text.
- Add page-specific title, description, Open Graph, and social-sharing metadata.

## Dependency
The reference screenshots were not available in the uploaded-files area during review. Implementation will use this scope and must compare against the screenshots once they become accessible; otherwise the result will use a distinctive logistics-focused direction rather than claim an exact visual copy.
